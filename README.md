A fast-paced browser typing game built with HTML, CSS, and JavaScript. Challenge yourself to type accurately and quickly before the timer runs out.

## Demo

Open the game in your browser and start typing the displayed paragraph.

## Features

- Random paragraph generation
- Countdown timer
- Live WPM tracking
- CPM calculation
- Mistake counter
- Accuracy percentage
- Best score saved in local storage
- Restart and new paragraph buttons
- Responsive layout for desktop and mobile screens
- Modern gaming-inspired interface

## How to Run

1. Clone or download the project.
2. Open the project folder.
3. Start a local server:

```bash
cd E:\Projects\Typing_game
python -m http.server 8000
```

4. Open your browser and visit:

```text
http://localhost:8000
```

## Gameplay

- Type the text shown on screen as quickly and accurately as possible.
- The timer starts as soon as you begin typing.
- Your WPM, CPM, mistakes, and accuracy are calculated live.
- Complete the paragraph before time runs out.
- Use the buttons to restart or generate a new paragraph.
